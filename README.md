# Nutricat — Projeto Integrado

Aplicação desktop em Java 21 + JavaFX 21.

## Executar

1. Abra a pasta `projetoDesktop` no IntelliJ IDEA como projeto Maven.
2. Aguarde o Maven baixar as dependências.
3. Execute `HelloApplication` ou rode `mvn javafx:run` no terminal.

## Acesso para apresentação

- Login: `1`
- Senha: `1`

Também existe o acesso `gerente` / `1234`.

## Módulos no menu principal

- Questionário de bem-estar com cinco temas e escala de emojis.
- Receitas, com informações de preparo, alérgenos e informação nutricional.
- Lembretes com horário.
- Cadastro demonstrativo de clientes e relatórios individuais.
- Gerenciamento de usuários, banimento, desbanimento e exclusão.
- Central de Ajuda e Denúncias, com visualização do print e banimento pelo ticket.
- Relatórios gerais com os cinco indicadores do questionário.

Os registros deste protótipo ficam em memória e são reiniciados quando o programa é fechado. Os dados e gráficos demonstrativos não representam avaliação clínica nem substituem acompanhamento profissional.
